# Security policy

This repository contains demonstration scenarios that use synthetic data only.

## Reporting a vulnerability

Please do not open a public issue. Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/rutgerpels/azure-agentic-ops/security/advisories/new).

Include the affected path, the steps to reproduce and the potential impact.

## Scope

- In scope: code, workflows and infrastructure templates in this repository.
- Out of scope: deployed demo environments, which are temporary, and
  third-party services.
